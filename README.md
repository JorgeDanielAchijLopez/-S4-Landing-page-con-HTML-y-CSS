# Moda Modela

Landing page desarrollada únicamente con HTML y CSS para una marca ficticia de ropa llamada **Moda Modela**.

El proyecto tiene como objetivo aplicar fundamentos de estructura semántica en HTML, estilos externos con CSS, navegación interna, accesibilidad básica y diseño responsive.

## Tecnologías utilizadas

* HTML5
* CSS3
* Visual Studio Code
* Live Server
* Git
* GitHub

## Estructura del proyecto

```text
/
├── index.html
├── styles.css
├── README.md
├── .gitignore
└── assets/
    └── moda-modela.jpg
```

## Características principales

* Estructura semántica con `header`, `nav`, `main`, `section`, `article` y `footer`.
* Uso de clases reutilizables y atributos `id`.
* Imagen con texto alternativo.
* Navegación interna mediante enlaces.
* CSS externo.
* Selectores de tipo, clase e ID.
* Uso de pseudoclases `:hover` y `:focus-visible`.
* Aplicación de `margin`, `padding` y `border`.
* Uso de unidades relativas.
* Diseño adaptable a dispositivos móviles.
* Navegación accesible mediante teclado.

## Cómo ejecutar el proyecto

1. Clonar o descargar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Instalar la extensión **Live Server** si aún no está disponible.
4. Abrir el archivo `index.html`.
5. Hacer clic derecho y seleccionar **Open with Live Server**.
6. La landing page se abrirá automáticamente en el navegador.

## Navegación

La página contiene las secciones:

* Inicio
* Colección
* Nosotros

Los enlaces del menú permiten desplazarse directamente hacia cada sección.
